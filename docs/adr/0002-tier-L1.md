# ADR-0002 — Tier de sécurité L1

**Statut :** Accepté · **Date :** 2026-08

## Contexte
Vitrine + formulaire de contact. Pas d'auth, pas de paiement, pas de PII stockée (§01).

## Décision
Tier L1 : headers sécurité + CSP (report-only → strict), Zod + honeypot + Turnstile
sur /api/contact, rate-limit 3–5 req/min/IP, pages légales FR, security.txt.
PAS de DB, Redis, auth, queues en v1 (§53 #15 : tier-aware).

## Triggers de montée de tier
- Compte/édition contenu → L2 (+ sessions server-side, CSRF, audit basic).
- Vente en ligne → L3 (Stripe, idempotency §22, webhooks signés §19, RLS §15).
